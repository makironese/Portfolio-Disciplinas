Matemática - Funções Quadráticas

O que é uma Função Quadrática?

Uma função quadrática é uma função do tipo:

f(x) = ax² + bx + c

Onde:

  • a, b e c são constantes (com a ≠ 0);
  • x é a variável independente;
  • O gráfico dessa função é uma parábola, que pode abrir para cima ou para baixo, dependendo do valor de a.

Propriedades da Função Quadrática

  • Vértice: O ponto mais alto ou mais baixo da parábola, dependendo de a parábola abrir para cima ou para baixo.
  • Coeficiente "a": Determina a concavidade da parábola. Se a > 0, a parábola abre para cima. Se a < 0, a parábola abre para baixo.
  • Raízes ou Zeros: São os valores de x que fazem com que a função seja igual a zero (f(x) = 0). Podem ser encontrados pela fórmula de Bhaskara.

Fórmula de Bhaskara

A fórmula de Bhaskara é utilizada para resolver equações quadráticas. Para uma equação do tipo:

ax² + bx + c = 0

A solução para x é dada por:

x = (-b ± √(b² - 4ac)) / 2a

Onde:

  • b² - 4ac é chamado de discriminante. Dependendo do seu valor, ele pode indicar:
    • Se b² - 4ac > 0, existem duas raízes reais diferentes;
    • Se b² - 4ac = 0, existe uma raiz real (a parábola toca o eixo x em um único ponto);
    • Se b² - 4ac < 0, não existem raízes reais (a parábola não toca o eixo x).

Exemplo:

Vamos resolver a equação x² - 5x + 6 = 0 utilizando a fórmula de Bhaskara:

a = 1, b = -5, c = 6

Calculando o discriminante:

Δ = (-5)² - 4(1)(6) = 25 - 24 = 1

Agora, aplicamos a fórmula de Bhaskara:

x = (5 ± √(1)) / 2 = (5 ± 1) / 2

Então, as raízes são:

  • x₁ = (5 + 1) / 2 = 3
  • x₂ = (5 - 1) / 2 = 2
